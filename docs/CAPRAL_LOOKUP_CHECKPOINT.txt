CAPRAL REFERENCE IMAGE LOOKUP — RELEASE CANDIDATE (21 NOVEMBER 2026)

Implementation is complete. Do not deploy until live image download and production
access are verified; see Pending below.

Behaviour
An administrator enters an editable Capral product/profile code, reviews an exact
matching product, chooses Use image, and saves through the existing stock editor.
Lookup is read-only. Stock codes, quantities and prices are retained. Existing
same-SKU photo sharing and idempotent stock saving are retained.

Verified live provider contract
- Capral home links to https://shop.capral.com.au/.
- Public native search: https://shop.capral.com.au/search.php?search_query=EP10189
  returns a card for https://shop.capral.com.au/943511/.
- The product JSON-LD binds SKU 943511 to its image. The productView-info block
  explicitly identifies SECTION EP10189 and SKU 943511. Profile matching requires
  exact SECTION, matching SKU and canonical product URL; titles are insufficient.
- Images use https://cdn11.bigcommerce.com/s-gwvwsryafm/images/stencil/… . Only
  Capral's specific store image path is accepted on that shared CDN. Product
  pages remain limited to apex/www/shop.capral.com.au. All redirects are checked.
- Search reads at most six canonical product cards; fetches remain bounded by
  bytes, redirects and timeout. Image use revalidates the exact-code association.
- Public supplier lookup can be rechecked read-only with:
  In panelstock: cd worker && NODE_USE_ENV_PROXY=1 node scripts/verify-capral-reference.mjs
  (NODE_USE_ENV_PROXY is needed only for Node environments using an HTTP proxy.)
