CAPRAL REFERENCE IMAGE LOOKUP — WORK IN PROGRESS

Do not merge or deploy this checkpoint. The live Capral search provider is
deliberately unconfigured until the official website can be inspected and tested.

Goal
Find a stock item's official Capral reference image using an editable Capral
product/profile code, review the matching product, choose Use image, then save
through the existing stock item editor. Keep stock codes, quantities and prices
unchanged. Existing image saving shares the photo across same-SKU variants.

Prepared implementation
- worker/src/capral-reference.js validates codes and official HTTPS URLs, bounds
  redirects/time/bytes, extracts exact-code JSON-LD products and revalidates image
  association before downloading PNG/JPEG/WebP. Only apex/www hosts are currently
  approved internally. searchCapralReference requires internal options.searchUrl;
  the production default is intentionally absent and returns 503.
- POST /stock-images/capral/search and /stock-images/capral/image authenticate a
  full administrator session, bound input and respect maintenance mode. These
  are read-only lookup routes; stock mutations still use the normal Save flow.
- workshopView advertises capralReferenceLookupVersion:1 in this draft. Complete
  the provider before deployment; otherwise the UI would expose an unavailable
  search.
- Both clients have editable Capral code, staged product/image previews, exact
  response-code checks, explicit Use image, upload-equivalent image preparation,
  cancellation/stale-response guards and ordinary idempotent stock saving.
- No actual customer stock, photos, prices or quantities were modified.

Validation so far

- 2 additional authentication/maintenance tests pass against local Miniflare.
- 19 UI tests pass through mobile, desktop and the Worker entrypoint.
- Full desktop suite: 179 test files pass. Worker deployment dry-run passes.
